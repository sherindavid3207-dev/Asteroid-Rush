# 🚀 Asteroid Rush

An immersive, arcade-style 3D space flight runner built in Unity. Navigate a high-speed cockpit through atmospheric skyboxes, dodge incoming asteroid fields, and experience fluid constant-forward flight mechanics.

---

## 🎮 Features & Technical Highlights

* **Automated Forward Propulsion**: Ship maintains continuous forward motion along the Z-axis, creating an endless flight paradigm.
* **Responsive Flight Dynamics**: Smooth WASD lateral steering with realistic procedural pitch, roll, and cockpit banking.
* **Space Dust Particles**: Dynamic particle system configured in world space to deliver realistic high-speed motion cues through the windscreen.
* **Atmospheric Environment**: Custom deep-space skybox materials paired with engine rumble camera feedback for enhanced immersion.

---

## 🛠️ Controls

| Action | Input |
| :--- | :--- |
| **Steer Left / Right** | `A` / `D` or `Left Arrow` / `Right Arrow` |
| **Pitch Up / Down** | `W` / `S` or `Up Arrow` / `Down Arrow` |

---

## 💻 Tech Stack

* **Engine**: Unity (6.x / URP)
* **Language**: C#
* **Input System**: Unity New Input System package
* **Version Control**: Git & Git LFS for binary assets (.mat, .fbx, .png)
